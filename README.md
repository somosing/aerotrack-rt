# AeroTrack-RT

UAV-specific real-time object detection and multi-object tracking.

This project is being rebuilt from first principles around:

- small-object aerial detection
- high-resolution UAV imagery
- moving-camera compensation
- robust multi-object association
- temporal detection recovery
- systematic detector/tracker benchmarking
- real-time edge deployment

The system will be developed and evaluated primarily on VisDrone before external generalization benchmarks are added.
